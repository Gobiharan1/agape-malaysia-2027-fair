WORDPRESS SETUP (ELEMENTOR)
1. Create a new WordPress page, e.g. Study in Malaysia Fair.
2. Open it with Elementor. Set Page Layout to Elementor Canvas to remove your theme's header, footer and automatic page title.
3. Add one full-width container. Set content width to Full Width, gap to 0, margin and padding to 0.
4. Add an HTML widget. Open wordpress-paste.html in a text/code editor and copy all the code into that widget. Do not paste the file as an attachment or into a text/paragraph widget.
5. Preview and test on a phone before publishing your ad destination.

WITHOUT ELEMENTOR
Use a Custom HTML block and your theme's blank, full-width template, disabling the page title, header and footer in the template settings. Exact controls depend on the theme. The snippet cannot remove theme output outside itself. WordPress must allow the embedded style, script and image data URLs. Some roles, multisite installations and security plugins filter these. If that occurs, use Media Library images and have an administrator add the script through the site's approved custom-code tool.
