# Agape Study in Malaysia 2027 Education Fair

Client preview of the Sri Lanka education fair landing page for Agape Education Malaysia.

- Colombo: 12 December 2026, Radisson Colombo, 10 AM–3 PM.
- Kandy: 13 December 2026, Radisson Kandy, 9 AM–3 PM.

The page is static HTML, CSS and JavaScript. Registration prepares a WhatsApp message; visitors review and send it themselves. No lead data is saved in this repository.

## WordPress

Copy the contents of `wordpress-paste.html` into an Elementor HTML widget on an Elementor Canvas page. For Media Library image URLs, use `wordpress-media-version.html` and follow `START-HERE.txt`.

## Preview locally

Serve this directory with a static HTTP server. There is no build step.
